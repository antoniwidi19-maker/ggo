# Belanjaku — Marketplace Starter

Starter project marketplace frontend menggunakan HTML, CSS, dan JavaScript murni.

## Menjalankan
1. Ekstrak ZIP.
2. Buka folder `belanjaku`.
3. Buka `index.html` di browser. Disarankan memakai VS Code + ekstensi Live Server.

## Fitur demo
- Beranda marketplace responsif.
- Pencarian dan filter kategori.
- Katalog produk.
- Keranjang belanja dengan ubah jumlah dan hapus.
- Login demo berbasis nama.
- Form tambah produk.
- Penyimpanan produk, keranjang, dan sesi demo melalui `localStorage`.

## Catatan penting
Ini adalah **prototype frontend**, bukan marketplace produksi. Login belum memakai autentikasi aman, belum ada database server, chat, dashboard admin, ongkir, pelacakan, maupun pembayaran nyata. Data hanya tersimpan di browser yang digunakan. Jangan gunakan untuk menerima pembayaran atau menyimpan data pribadi sungguhan.

## Pengembangan berikutnya
Integrasikan backend (misalnya Supabase), autentikasi, database, storage gambar, role pembeli/penjual/admin, validasi server, dan payment gateway resmi dalam mode sandbox sebelum produksi.
